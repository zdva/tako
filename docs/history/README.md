# 开发档案

这里保存 2026-11 各里程碑的范围说明和当时的验收记录，避免它们占着仓库首页。

当前怎么用，看 [用户手册](../MANUAL.md) 和仓库根目录的 [README.md](../../README.md)。各版本改了什么，看 [CHANGELOG.md](../../CHANGELOG.md)。一条决定是否仍然有效，看 [ADR 的状态](../adr/README.md)。

| 文件 | 内容 |
|---|---|
| [milestones.md](milestones.md) | M1–M4 各自交付了什么，以及哪些说法后来被取代 |
| [acceptance.md](acceptance.md) | 从 CHANGELOG 移出的验收表和当时的测量数字 |

这些数字是那次构建、在那台 Linux 机器上的记录。它们不是对 `main` 今天的性能或覆盖率承诺。
