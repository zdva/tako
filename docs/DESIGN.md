# Tako（章鱼终端）设计规范 · 交互与视觉定稿 v1

所有效果图都由 `src/` 下的 HTML/CSS 渲染（1440×900，@2x，Chrome headless），文字全部来自代码，不是 AI 生图，所以下面的色值、字号、间距就是实际量出来的数值。重新生成：

```bash
cd src && node build.js && ./render.sh main-light main-dark empty-state add-host disconnected transfer monitor minimap-states palette
```

`src/base.css` 的 CSS 变量就是设计 token 的源头。

## 1. 设计原则

1. **安静的原生感**：参考 Magpie——浅灰底、白色圆角卡片、1px 低对比描边、很轻的阴影。控件不抢戏，终端内容才是主角。
2. **珊瑚色只表示“同步/主操作”**：同步状态、主按钮、选中态用章鱼的珊瑚色。监控图表用蓝/紫/青/绿/琥珀，避免和同步混淆。
3. **状态一眼可读**：同步（珊瑚边框 + 顶部 2px 色条 + “同步中”徽标）、断线（琥珀色）、在线（绿点）。同一状态在块头、侧栏、小地图、状态栏里用同一种颜色。
4. **终端主题跟随应用**：亮色用白底终端，暗色用近黑终端，ANSI 色针对两种背景分别调过对比度。终端主题以后可单独设置。
5. 无顶部分段标签、无工作区名称、无危险命令确认弹窗。

## 4. 交互说明

### 4.1 状态

| 状态 | 表现 |
|---|---|
| Hover | 背景加深一级（`--surface-3`），150ms 渐变；终端块头出现标签页关闭 ×。 |
| Pressed | 比 hover 再深一级，按钮缩放 0.98。 |
| Focus（键盘） | 2px `--accent-ring` 外环；终端块聚焦时光标为实心，未聚焦为空心。 |
| Selected | 列表行：白底 + 描边；文件行：珊瑚淡底 + 左侧 2px 色条。 |
| Disabled | 文字 `--text-3`，不响应。 |

### 4.2 动画

- 默认 **弹簧 ≈150ms**（阻尼 1.0，无回弹，用于布局重排、面板出现、方块拖动落位）。
- 颜色 / 透明度渐变 120–150ms。
- 弹层出现：遮罩淡入 + 面板 8px 上移淡入，200ms。
- 系统开启“减少动态效果”时，一律改为直接切换。

### 4.3 布局与吸附

- 自适应网格：1 块铺满，2 块左右平分，3–4 块 2×2，5–6 块 3×2，更多则竖向滚动；每块有最小尺寸（见 §6 说明）。
- 块之间的分隔线吸附到 1/2、1/3、2/3，吸附时显示珊瑚色参考线；按住 ⌥ 临时关闭吸附。
- 小地图：拖动时吸附到窗口四角和四边中点（间距 20px），松手后弹簧归位；方块拖动时主区块实时重排，松手后吸附到网格。
- **框选**：在小地图空白处拖出虚线框，框内方块统一切换同步；⇧ 追加，⌥ 反选。
- **同步输入**：焦点块的键盘输入会发送到所有“同步中”的块；终端自动回复的信号（如光标位置回报）不会同步。断线的块自动跳过。

### 4.4 断线

- 块内显示琥珀色横幅：“连接已断开 · 重连中（第 N 次）”、倒计时、“立即重连”。
- 内容变淡，并插入“连接中断 hh:mm:ss”分隔线。
- 用户在断线块里敲键时，底部浮卡提示“断线期间的输入不会发送”，**不缓存、不补发**。
- 该块同步开关变成“同步已暂停”，其余同步块不受影响；侧栏变琥珀点，小地图方块变琥珀虚线，状态栏显示“N 台重连中”。
- 重连策略：1、2、5、10、30 秒递增，之后每 30 秒一次，永不放弃，用户可手动关闭块。

### 4.5 文件传输

- 三种方式：上传（本机→服务器）、下载（服务器→本机）、服务器互传（A→B）。
- 互传默认**经本机中转**（不要求两台服务器互通），可选“直连 scp / rsync”（需要 Agent 转发）。
- 队列项显示进度、速度、剩余时间；网络中断自动暂停，保留偏移量，点“继续”从断点处续传，完成后校验。
- 拖动文件到任一窗格即上传到当前目录；窗格之间点中间的 → 开始传输。

### 4.7 右键菜单

- **主机行**：打开 / 在新块中打开 / 加入同步 / 监控 / 传输文件… / 编辑 / 复制地址 / 复制 SSH 命令 / 删除。
- **终端块头**：重命名 / 在新标签页复制会话 / 同步开关 / 监控 / 传输文件… / 移动到… / 关闭块。
- **终端内**：复制 / 粘贴 / 全选 / 清屏 / 搜索 / 在新标签页打开当前目录（用 OSC 7 取得目录）。
- **小地图方块**：切换同步 / 聚焦该块 / 关闭该块。
- 菜单：圆角 10、`--shadow-lg`、行高 28、分组之间 1px 分隔线，快捷键右对齐灰字。

### 4.8 其他

- **会话恢复**：退出时保存块、标签页、布局、同步状态、小地图位置和透明度，下次启动自动重连。
- **深色模式**：跟随系统，设置里可强制。
- **语言**：中文 / English，所有文案走本地化表（效果图为中文）。
- **敏感信息**：密码和口令只存在系统钥匙串（`mygo.Secrets`），配置文件里不写明文。

## 6. 已知取舍（需要你决定）

1. **最小块尺寸与 3×2**：规格里写的最小约 80×24 列，但在 1440 宽、侧栏展开时，3 列每块只有约 49×17。效果图展示的就是这种“紧凑”状态。建议：窗口不足以放下 80 列时，自动退到 2 列并纵向滚动；用户可在设置里把“最小块”改成紧凑（约 48×16）。
2. **小地图会遮住右下角块的一部分**：这是浮动面板的代价，可拖走、可调透明度，也可以 ⌘⌥G 隐藏。
3. **系统图标是简化版**：Windows 用四宫格，macOS 用 ⌘ 字符，Linux 用服务器图标；上线前建议换成统一的发行版 / 系统图标。
4. **提示符里的 `❯`** 在效果图里走了回退字体，实际由终端字体决定。
5. 效果图是静态 HTML，不是 MyGo 渲染的结果；毛玻璃、阴影的实际观感要在 MyGo 里实测后微调。

## MyGo 实现提示（v2）

- 负载圆点 + 悬停详情：`ui/tooltip.go` 或 `ui/popovermenu.go` 的自定义内容；监控数据已经按 1 秒采样，直接复用。
- 小地图“静止半透明 / 悬停不透明”：`plugins/glass` 的 tint alpha 做 150ms 动画；`ui/motion` 的颜色动画即可。
- 侧栏悬停显示 IP：行内的悬停态，不需要 tooltip。

## v2 的取舍

1. 悬停详情是“按需”的，截图里只能展示一个块的悬停态；实际使用时需要把鼠标移到圆点上才能看到数值，**一眼扫全局的资源概览没有了**，需要时点工具栏的监控图标。
2. 负载圆点只取 CPU / 内存 / 磁盘最大值，GPU 机器想看显存告警要进悬停条或监控页。
3. 终端字号缩小 0.5px 换来约 5 列；如果觉得偏小，设置里调回 12px 即为 52×20。
4. 小地图方块标签仍是完整主机名，176px 宽时 `win-build` 已经很紧；主机名更长时需要省略或改用序号。

# Final（定稿）

文件：`out/final/` 下 9 张图（`main-light`、`main-dark`、`empty-state`、`add-host`、`disconnected`、`transfer`、`monitor`、`minimap-states`、`palette`）。v1、v2 的文件原样保留。源码：`src/lib3.js`、`src/final.css`、`src/s_f_*.js`，用 `./render-final.sh <名字>` 渲染。

## 定稿基线

- **以 v1 为底**：每块保留块脚的资源条（CPU / 内存 / 磁盘或 GPU + 延迟），终端字号 12px / 行高 18，约 49×17；侧栏保留两行主机（名称 + `user@ip`）。
- **小地图**：宽 176px、高约 92px；静止时背景 50% 透明（`--glass2`）+ 16px 模糊，同步方块 85% 不透明；**鼠标悬停或拖动时整体变为不透明**（`--glass3`，方块 100%，150ms 渐变）。标题行只放拖动把手、`同步 n / 6` 计数和透明度滑块。
- **同步状态**：沿用 v2 的轻量写法——1px 珊瑚淡边框（`--sync-border`）+ 块头一个小的“同步”chip（开：珊瑚淡底 + 珊瑚字；关：灰色描边）。去掉粗边框、顶部色条和实心按钮。如果更喜欢 v1 的醒目写法，只需改 `.fin .sync-chip.on` 与 `.fin .block.synced` 两处。
- **任何一个操作在界面上只保留一个可见入口**，其他路径放进快捷键、右键菜单和 ⌘P 命令面板。
